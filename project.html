04 Submission & Evaluation

Submission Package (P<N>_<StdID>.zip)

  • Private GitHub Repo: Modular codebase with requirements.txt, README.md, and the exact submission commit hash on page 1 of your report.
  • Run Outputs: One folder per run containing predictions.jsonl and run_config.yaml following predictions_format.md.
  • Technical Report: Concise PDF (max 3 pages) covering implementation choices, metric tables, comparisons, and error analysis.
python score.py <predictions_file.jsonl> --pack course_pack_v1 --split dev

Grading & Oral Defense

  • Grade Split: ~40% for code correctness, predictions, and report; 60% for the live oral defense and technical comprehension.
  • Oral Check-In (10–15 mins): Live pipeline run on 3–5 queries, inspection of handcrafted core mechanisms, and live parameter/prompt adjustments.
  • Academic Integrity: Peer discussion and AI coding assistants are permitted, provided you personally understand and can modify all submitted code live.

05 Late Policy & Engineering Bonus

Deadlines & Grace Budget

48-Hour Grace Budget 48 free grace hours across the semester without penalty.
Late Deduction 0.5 points deducted per hour (out of 100) after grace hours are exhausted.
96-Hour LMS Window Submission portal stays open 4 days past the deadline for late submissions.
Early Bonus Up to 24 bonus grace hours restored for early submissions scoring >80%.

Software Engineering Extra Credit

  • Structured Configs: Centralize hyperparameters in YAML generating run_config.yaml.
  • Unit Tests: Lightweight pytest suite verifying handcrafted metrics, masking, RRF, and parsers.
  • CI Workflow: GitHub Actions running unit tests automatically on every push.
  • Experiment Tracking: Clean MLflow (SQLite) or Weights & Biases run logs linked to report tables.
